# Git Commit Guidelines

When providing git commands or commit messages, strictly follow this format:

1. Provide the `git add` and `git commit` commands as plain text.
2. DO NOT use markdown code blocks (e.g., ```bash) if there is a risk of the interface adding line numbers.
3. The commit message must include:
   - A concise subject line.
   - A list of main changes (using dashes '-' instead of numbers).
4. Ensure no line numbers are present in the output.
5. Provide the commands exactly as they should be pasted into the terminal.
